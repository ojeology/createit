# CREATEIT — Brand & Visual Design Brief

## 1. What CreateIt is
CreateIt is a mobile **competition platform**. Anyone can post something uniquely theirs, challenge the world to recreate it, and compete to beat it. It rewards **skill and uniqueness — not followers**.

- **Tagline:** Create It. Recreate It. Beat It.
- **Core belief:** *"You don't need to be famous. You need something uniquely yours."*
- **The central object is THE CHALLENGE.** The loop:
  **CREATE → RECREATE IT → BEAT IT → CHAMPION → RECORD → JOURNEY**

## 2. Brand personality
- Confident · Energetic · Bold · Premium · Youthful (but **not childish**)
- Competitive like a sport, creative like an art form
- **NOT** a TikTok / Instagram / YouTube clone — its own identity
- **Reference energy:** a sports-championship broadcast meets the polish of Spotify / Nike

## 3. Visual direction
- Bold, colorful, energetic, premium
- Deep dark base with vivid, energetic accents
- Strong, dramatic display typography
- Confident gradients used tastefully (not rainbow noise)

## 4. Color palette (current system — refine, don't reinvent without a better idea)
| Role | Color |
|---|---|
| Base / background | deep charcoal `#06080E` |
| Fire (primary / Beat It) | `#FF5A2E → #FFB020` gradient |
| Gold (Champion / Records) | `#FFC21A` |
| Teal (Recreate / success) | `#14E0B0` |
| Violet (Create) | `#8B5CFF` |
| Blue (Judging) | `#3D8BFF` |
| Text | `#F4F6FA` / muted `#8E97AB` |

## 5. Typography
- **Display:** bold, condensed, dramatic (Anton / Impact style) — headlines, scores, big numbers
- **Body / UI:** clean modern sans (Inter style)
- **Mono / technical** (optional): labels, stats, codes

---

## 6. DELIVERABLES

### A. Logo / Wordmark
- Primary wordmark: **CREATEIT** with **"IT" as the accent** (fire→gold gradient)
- A **standalone symbol** that works alone (app icon, favicon)
- **Concept direction:** creation + competition + upward achievement. Combine a *spark/flame of creation* with *victory (crown / rising)* if possible.
- **Variations needed:**
  - Full horizontal wordmark
  - Stacked version
  - Symbol only
  - Monochrome (all-white + all-black)
  - Light-mode and dark-mode versions

### B. App Icon (Android adaptive)
- Square with safe zone for adaptive icon
- Foreground symbol + background color/gradient
- Must stay clear and recognizable at small sizes

### C. Splash Screen
- Logo reveal moment, dark background, premium feel
- Should feel like the start of an event

### D. UI Style Guide / Component Look
- Buttons (primary fire gradient, secondary, ghost)
- Cards, pills/badges — **stage pills:** Create=violet, Recreate=teal, Beat It=fire, Champion=gold
- Navigation bar style
- Section headers
- Score / number treatment

### E. Illustrations & Iconography
- Empty-state illustrations (e.g. "no content yet")
- Achievement / trophy motifs
- One consistent icon set (single stroke weight/style)

---

## 7. Things to AVOID
- Generic social-media look (TikTok / IG / YT clones)
- Childish or cartoonish style
- Rainbow overload / too many competing colors
- Generic corporate / flat "SaaS" look
- Overly literal or clip-art icons
